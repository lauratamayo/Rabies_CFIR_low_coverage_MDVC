# Rabies_CFIR_low_coverage_MDVC
This repository contains focus group transcripts and annotation data used in the study "An Implementation Science Framework to Understand Low Coverage in Mass Dog Rabies Vaccination," published in 2025 in PLOS Neglected Tropical Diseases.

The dataset includes:

Full transcripts from focus group discussions with community members conducted as part of the study.
Annotation files from focus group discussions held with authorities and program implementers.
